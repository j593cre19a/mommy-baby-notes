# 签约妇幼保健医联体  优质医疗服务辐射基层

> 更新时间：2026-09-11 (UTC+8)

5月16日，南宁市妇幼保健院与扶绥县妇幼保健院举办妇幼保健医联体签约揭牌仪式。南宁市妇幼党委书记蒋武、副院长庞智东，扶绥县卫生健康局党组书记、局长李华剑，扶绥县妇幼保健院党总支副书记、院长梁威丽，南宁市妇幼医联办、生殖医学中心、儿科和儿童保健科等科室负责人，扶绥县妇幼职工代表参加了仪式。

在签约仪式上，李华剑对南宁市妇幼相关领导及专家表示诚挚的谢意。他表示，两家妇幼机构的合作是扶绥县深化医药卫生体制改革工作中的一件大事，必将推动扶绥县妇幼健康事业的进一步发展，南宁市妇幼的医疗资源下沉一定能不断提高扶绥县妇幼的医院管理、诊疗技术和服务水平，为扶绥县及临近县的人民群众提供更加优质、高效、便捷的健康服务。

蒋武书记（左）与梁威丽院长（右）共同签署妇幼保健医联体协议书

蒋武表示医联体的组建，标志着两家妇幼保健院进入到了一个崭新的互助发展阶段，双方精诚合作，开展全方位、多维度的交流学习，必定能为整体提升广西妇幼保健服务能力、提高扶绥县辖区妇女儿童健康水平增添一支新的力量。南宁市妇幼将继续激发医联体党建创新能力，坚持党建引领，在党建共建、疾病防治、人才培养、技术指导、双向转诊、资源共享等方面加强与扶绥县妇幼合作，加速妇幼服务体系同质化进程，努力为保障妇女儿童健康做出新的贡献。

参观新院区

在出席仪式的领导和专家的见证下，蒋武与梁威丽共同签署了妇幼保健医联体协议书。签约仪式后，蒋武书记、李华剑局长、梁威丽院长、庞智东副院长共同为医联体揭牌。在梁威丽院长的陪同下，南宁市妇幼蒋武等到各临床科室和新院区进行参观调研。当天上午，南宁市妇幼联合扶绥县妇幼开展健康咨询公益活动。专家团队为前来就诊的群众提供健康咨询与指导，耐心细致地为每一位群众解答各种疑难问题，并提供科学合理的诊疗建议。活动现场气氛热烈，闻讯前来就诊的患者及家属络绎不绝，受到广大患者的热烈欢迎和高度肯定。

市妇幼多学科专家为当地百姓提供健康咨询

下一步，南宁市妇幼将始终坚持以人民健康为中心，坚持把社会效益放在第一位，坚持“连体+连心”，实现医院管理、学科建设、医疗保健和技术应用等双向合作与资源共享，力求同质化、便利化、精准化，实现“错位发展、优势互补”的目标，为推动妇幼保健事业持续快速发展、提高妇女儿童健康水平贡献更大的力量。
