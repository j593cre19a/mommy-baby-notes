# 南通市妇幼保健院试管婴儿取卵手术是全麻吗?

> 更新时间：2026-09-19 (UTC+8)

34岁做准备做试管婴儿生二胎，用的短方案促排，这几天一直在检测卵泡发育的情况。昨天医生看了，说再过两天就可以做取卵手术了，我自己是个很怕痛的人，很紧张，网友们都说取卵手术超级痛，有的医院是会打局部麻醉的，有的医院连麻醉都不给打，不知道南通市妇幼保健院取卵打不打麻醉？能不能打全麻？

一般在南通市妇幼保健院进行试管取卵是能够打麻药，也可以做全麻，但是正常情况下是选择进行局部麻醉的。而且如果要去进行麻醉取卵的女性，不建议星期天去，因为星期天一般没有麻醉医生在，所以取卵想要全麻的女性，可以事先和试管医生进行沟通，安排好取卵时间。

但是试管婴儿取卵，一般情况下不建议采取麻药。如果用麻药的话，不排除会对卵子造成一定影响的可能。建议放松心态，不要过度紧张，过度紧张的话可能会使疼痛感加重。到医院做彩超检测卵泡，卵泡成熟的话，取卵进行体外受精，如果受精卵发育比较好的话，三天以后就可以进行胚胎移植。

并且在取卵前要注意生活有规律，早睡早起，避免熬夜，避免过度劳累。同时饮食上要注意清淡，尽量不吃荤腥油腻、辛辣刺激饮食，多喝水。适量运动，保持良好的身体机能，尽量保持平和的心态，避免焦虑，这样才有助于卵子的生长，并且在取卵后还要注意以下几点。

- 1. 取卵之后可有轻微的下腹部疼痛，所以需要卧床休息1-2天；
- 2. 因为促排卵的时候卵巢比平时增大，所以为了预防卵巢扭转，日常活动翻身的时候要平稳；
- 3. 禁止剧烈活动，禁止性生活及阴道冲洗；
- 4. 如果突发剧烈性的下腹部疼痛，发烧，阴道出血，迅速到医院。

只要按照医生医嘱进行相关取卵准备适宜，南通市妇幼保健院取卵的数目基本上都是比较可以的。跟着医生的节奏，基本上没有什么问题。取卵时是否全麻或者局麻，一定要和医生根据自身情况进行沟通。
虽然全麻和局麻取卵都是麻醉取卵，但是还是有区别的，全麻也就是全身的麻醉，当打完后基本什么都不知道了，而局麻是只对需要做的地方进行麻醉，人还是处于清醒的状态，至于需要打那个取决于取卵者，不还最好听取医生的建议为好。
