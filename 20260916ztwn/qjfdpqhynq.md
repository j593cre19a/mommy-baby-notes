# 精准微创解痉挛 康复治疗新突破一一齐鲁二院开展周围神经射频消融术

> 更新时间：2026-09-16 (UTC+8)

近日，山东大学齐鲁第二医院康复医学中心成功开展首例周围神经射频消融术，为一名68岁痉挛性四肢瘫痪老年女性患者实施精准微创治疗，术中患者肌张力显著改善、术后效果满意，为康复后遗症期肌张力障碍患者开辟了安全、高效、无创的治疗新路径。

患者因缺血缺氧性脑病导致四肢瘫痪4月余来院就诊，诊断为痉挛性四肢瘫痪。患者以右上肢屈肌、右手屈肌重度痉挛为主要突出表现，长期伴随张力性疼痛，经规范康复训练、药物等传统方案治疗后效果欠佳，严重影响患者上肢功能及日常生活。

经康复医学中心神经康复病区医技团队全面系统评估，患者右上肢屈肌肌张力改良Ashworth分级4级，右手屈肌张力改良Ashworth分级4级，属于重度痉挛，常规保守治疗已难以满足临床需求。团队结合科室新技术申报方案与患者实际病情，拟定周围神经射频消融术治疗方案，在与患者及家属充分沟通手术原理、预期疗效、潜在风险及应对预案后，家属表示充分理解并签署知情同意。

手术当天，康复医学中心常务副主任曾凡硕、副主任黄来刚带领团队，在局部麻醉下，采用超声联合影像精准定位，为患者行右上肢肌皮神经、正中神经射频消融治疗。手术在超声精准定位下规划穿刺路径，规避血管、肌腱及感觉神经；射频电极精准置于靶神经运动支旁安全区间，循序渐进调控温度、分点多次规范热凝消融，全程实时监控热凝范围，守护正常组织与神经功能。

手术全程微创、可视化操作，精准阻断痉挛肌肉的异常神经传导，最大程度保护正常神经与运动功能。术中即刻评估显示患者右上肢屈肌张力降至1级，右手屈肌张力降至1+级，痉挛状态快速缓解，疼痛明显减轻，术后无需缝合，仅局部止血包扎即可。手术过程平稳顺利，患者耐受良好，术后查体效果满意。

本次开展的周围神经射频消融术是科室的医疗新技术，依托成熟的射频治疗体系、超声精准定位及多学科协作保障，具备多重临床优势，可以实施精准靶向治疗，选择性作用于痉挛神经分支，不影响正常肢体功能；术中即可显著降低肌张力、缓解疼痛，快速起效，为后续康复训练创造条件；且局麻操作、创伤小、恢复快，有效改善肢体活动能力，帮助患者恢复独立生活能力，减轻家庭照护负担。该技术主要适用于脑卒中、脑外伤、脊髓损伤等导致的中重度肢体痉挛患者，尤其对改良Ashworth分级Ⅲ级及以上、常规康复与药物治疗效果不佳的患者，具有不可替代的治疗价值。

近年来，康复医学中心持续推进医疗新技术临床应用，不断优化康复诊疗流程，聚焦脑卒中后遗症、脊髓损伤、运动损伤等疑难病症，为患者提供全周期、个体化、高品质的康复医疗服务。未来，科室将继续以患者需求为导向，深耕精准康复、微创康复领域，向精准化、微创化、高效化方向高质量发展，以更先进的技术、更优质的服务，助力患者早日回归家庭、回归社会。
